# Changelog

## 0.1.0

- Initial independent clients for Python, TypeScript, PHP, .NET, Go, Rust, Ruby.
- Four public-service endpoints, optional provider key, typed errors, preserved
  unknown response fields and exact decimal balance strings.
- Mocked contract tests; purchases are never automatically retried.
- Static English, Russian and Uzbek documentation with canonical/hreflang,
  sitemap and guarded Postman/OpenAPI artifacts.
