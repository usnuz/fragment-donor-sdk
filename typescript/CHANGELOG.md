# Changelog

## 0.1.2

- Removed obsolete public header names and wallet-funding recommendations from
  package documentation while preserving neutral credential-transmission facts.
- Refreshed package metadata and release artifacts for the corrected public text.

## 0.1.0

- Dedicated uncertain-purchase errors for backend HTTP 400 `unconfirmed: true`.
- Explicit injected-transport connect-timeout configuration and abort contract.
- Exact built tarball/known-secret gates and installed-artifact regression for
  both unconfirmed gift operations.

- Four typed operations, form-urlencoded purchases, and exact balance strings.
- No service authentication; optional provider Api-Key only.
- Structured errors and bounded opt-in read-only retry/waiting.
- No automatic purchase retry, no redirects, and credential redaction.
- Strict typecheck, shared fixture tests, and release package metadata.
